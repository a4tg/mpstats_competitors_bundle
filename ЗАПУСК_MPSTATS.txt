MPSTATS — ЗАПУСК

1. Положите в одну папку:
   - mpstats_competitors.py
   - requirements.txt
   - запросы 62 SKU.xlsx

2. Откройте CMD / PowerShell в этой папке.

3. Один раз установите зависимости:
   py -m pip install -r requirements.txt

4. Запустите:
   py mpstats_competitors.py

5. При первом запуске откроется отдельный Chrome-профиль.
   Войдите в MPSTATS вручную. Пароль и cookies в код не записываются.
   После появления авторизованной сессии скрипт продолжит сам.

6. На выходе появятся:
   - mpstats_competitors.xlsx — итог
   - mpstats_cache.sqlite3 — кэш для продолжения после остановки
   - mpstats_profile — отдельный Chrome-профиль для MPSTATS

ПО УМОЛЧАНИЮ:
- TOP-10 запросов на каждый SKU
- только строки "Тематический кандидат" = Да...
- 4 параллельных HTTP-запроса
- до 50 главных конкурентов на каждый наш SKU
- собственные 62 SKU исключаются автоматически

Листы результата:
- Сводка — параметры запуска
- Запросы — какие запросы реально прогонялись
- Выдача — сырые товары MPSTATS по каждому запросу
- Конкуренты — агрегированный рейтинг конкурентов по каждому нашему SKU
- Ошибки — запросы, которые не удалось получить

Если MPSTATS вернет 429:
скрипт сам подождет и повторит запрос. Не увеличивайте MAX_WORKERS без необходимости.

Если закрыть скрипт:
запустите его снова. Уже полученные ответы будут взяты из SQLite-кэша.

НАСТРОЙКИ:
в начале mpstats_competitors.py есть блок "НАСТРОЙКИ".
Самые полезные:
TOP_QUERIES_PER_SKU = 10
THEMATIC_ONLY = True
COMPARABLE_ONLY = False
MAX_WORKERS = 4
TOP_COMPETITORS_PER_SKU = 50
